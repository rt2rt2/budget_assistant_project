# Бюджетный помощник (интервальные запросы)

Консольная программа для учета ежедневных расходов за один месяц. Пользователь добавляет траты в формате день, сумма, категория и получает сумму расходов за любой период с дня A по день B за O(1)

## Возможности

- Добавление расхода с указанием дня, суммы и категории
- Отмена последнего добавленного расхода
- Сумма расходов за выбранный период с дня A по день B за O(1)
- Общая сумма расходов за месяц
- Поиск дня с максимальным расходом
- Топ-5 категорий по суммарным тратам
- Статистика по категориям с суммой, числом трат, средним чеком и долей в процентах
- Задание лимита траты для категории и проверка превышения лимитов
- Вывод всех трат по возрастанию суммы
- Вывод трат в заданном диапазоне суммы
- Текстовая диаграмма расходов по дням

## Используемые структуры данных и алгоритмы

- Префиксные суммы. Массив накопленных расходов обновляется при каждом добавлении и каждой отмене, и сумма за выбранный период считается за O(1)
- Стек для отмены последнего добавленного расхода
- Бинарное дерево поиска для хранения трат. Симметричный обход по BST выводит все траты по возрастанию суммы, а выборка по диапазону отбирает траты с суммой от и до заданной
- Сортировка вставками для сортировки категорий по сумме трат
- Линейный поиск для дня с максимальным расходом

## Команды меню

После запуска на экран выводится меню, команда выбирается вводом ее номера

Команда 1 добавляет расход и запрашивает день от 1 до 31, сумму и категорию
Команда 2 отменяет последний добавленный расход и убирает его из всех структур
Команда 3 считает сумму расходов за период (день A и день B можно вводить в любом порядке)
Команда 4 показывает день с максимальным расходом
Команда 5 показывает общую сумму расходов за месяц
Команда 6 выводит топ-5 категорий по тратам
Команда 7 выводит статистику по категориям с суммой, числом трат, средним чеком и долей
Команда 8 задает лимит траты для выбранной категории
Команда 9 сравнивает траты по категориям с заданными лимитами
Команда 10 выводит все траты по возрастанию суммы
Команда 11 выводит траты с суммой в заданном диапазоне
Команда 12 рисует текстовую диаграмму расходов по дням
Команда 0 завершает работу программы

## Внутреннее устройство

Программа разбита на три файла. В model.py лежат структуры данных и класс Ledger, который ведет учет расходов. В analytics.py собраны отчеты и аналитика. В main.py находится консольное меню и главный цикл

Класс BST реализует бинарное дерево поиска со вставкой, удалением, симметричным обходом и выборкой по диапазону суммы. Класс Node хранит один расход, ключом служит пара из суммы и номера, дополнительно сохраняются день и категория
Класс Stack хранит номера расходов для отмены последнего добавления
Класс Ledger связывает все структуры. Список records содержит все траты, словарь by_id дает доступ к расходу по номеру, счетчик next_id выдает уникальные номера, массивы daily и prefix отвечают за дневные и накопленные суммы, дерево tree хранит траты по сумме, стек undo_stack помнит порядок добавления, словарь limits хранит лимиты по категориям
